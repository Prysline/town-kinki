# TOWN 繁體中文 Web 移植計畫

這是與原始 Perl/CGI 並行的 **Web 移植雛形（階段四，持續開發）**。原始檔案保留在儲存庫根目錄，Web 程式獨立放在 `web/`，不會覆寫原版遊戲。

## 本階段已完成

- 使用同一套 JavaScript 遊戲規則支援 `solo`（單機）與 `multi`（多人）模式。
- 使用 Node.js HTTP 伺服器與 SQLite 儲存資料，不必安裝 Apache 或啟用 CGI。
- 繁體中文城鎮與主要操作介面。
- 從原版 `dat_dir/job.cgi` 讀取職業資料，保留原始名稱與穩定識別碼，逐步提供繁體中文名稱。
- 根據原版進行角色配點：頭腦 200、身體 200、其他 100，各項需為正整數。初始現金 100,000 元並從日薪打工開始。
- 工作冷卻、身體與頭腦最大能量依原版公式計算；增加目前職業的經驗、等級、職業精通和進階職業解鎖。
- 工作薪資依出勤週期結算，包含原版的等級加薪與升級獎金計算。
- 銀行基本存款與提款（不含原版存款利息、定期存款、明細）。
- 從原始 `dat_dir/school.cgi`、`dat_dir/gym.cgi` 載入課程與訓練內容，建立繁體中文介面，支援支付費用、扣除能量與能力提升。
- 學校按照原始說明書實施每日一堂課；健身房的冷卻時間暫以原始訓練資料欄位的分鐘數實作。
- 多人模式帳號註冊、登入、登出，以及同城其他玩家名單。
- HTTP Only 工作階段 Cookie，密碼以 scrypt 雜湊儲存。
- 使用 Node.js 內建測試工具執行核心邏輯測試。
- 依 `top.pl` 與 `admin2.cgi` 還原原版 12 列（A 至 L）、16 欄（1 至 16）街區地圖，使用原版城市背景與設施圖示；單機可直接編輯、多人可共用已匯入的地圖。
- 支援從 `log_dir/townlog0.cgi` 至 `townlog3.cgi` 匯入原版 `<>` 分隔格式，保留原始欄位與未知設施代碼，並提供離線匯入／匯出指令。

**尚未完成：** 與原版遊戲規則完全一致、原版既有街區配置資料與房屋／建築互動、原版角色資料匯入、完整職業條件與工作狀態計算、原版訓練的額外效果與特殊事件、商店／道具與交易、銀行利息與帳戶明細、婚戀育兒、戰鬥、管理介面及全面翻譯。此版本主要提供可驗證的垂直功能切片，不應當作原版的完整替代品。

## 環境

需要 **Node.js 22.13 以上**，使用內建 `node:sqlite`（此功能在 Node.js 22 仍會顯示實驗性功能警告）。不需要外部 npm 套件。

```sh
cd web
npm test
npm start
```

預設進入單機模式，開啟 http://127.0.0.1:3000 即可建立角色。資料存於 `web/data/solo.sqlite`，瀏覽器清除 Cookie 不會刪除本機角色。

多人模式：

```sh
cd web
GAME_MODE=multi HOST=127.0.0.1 PORT=3000 npm start
```

接著在同一個地址開啟網站，各玩家可以分別註冊帳號。若需供其他裝置連線，請在可信任的 HTTPS 反向代理後部署，設定 `HOST=0.0.0.0`、`COOKIE_SECURE=1`。目前尚無登入速率限制、正式部署安全審查及備份管理，**不建議直接公開至網際網路**。

Windows PowerShell 可使用：

```powershell
cd web
$env:GAME_MODE = "multi"
npm start
```

單機與多人資料庫**彼此獨立**，但使用相同的規則、資料結構與前端介面。目前不支援兩者之間自動同步或轉移角色。

## 移植架構

```text
web/
  src/engine.mjs       共用遊戲規則、職業資料解析與翻譯
  src/server.mjs       Node.js 伺服器、SQLite、登入與 Web API
  src/training.mjs     舊版學校、健身房資料解析與訓練規則
  src/town-map.mjs     原版城鎮資料格式、格子及安全的圖示對照
  src/town-storage.mjs SQLite 城鎮地圖儲存與原始檔匯入
  scripts/town-map.mjs 街區離線匯入／匯出指令
  public/index.html    繁體中文網頁
  public/app.js        瀏覽器互動
  public/style.css     RWD 介面
  tests/engine.test.mjs  遊戲規則測試
  tests/server.test.mjs  單機與多人 API 測試
  tests/training.test.mjs 舊版訓練資料與時間限制測試
  tests/town-map.test.mjs 原版街區格式、符號及 SQLite 測試
```

資料來源：`../dat_dir/job.cgi`、`../dat_dir/school.cgi`、`../dat_dir/gym.cgi`，以及 `../log_dir/townlog{0..3}.cgi`（若非空）。若檔案為 UTF-8 或 Shift_JIS，會以解碼器讀取。原始的 `<> ` 分隔欄位不變，**不直接把日文識別值翻譯成中文**，避免破壞事件與職業相依關係。現階段沒有覆蓋到的職業名稱會保留日文以便逐項核對。

遊戲設定中沿用原版 `town_ini.cgi` 的工作冷卻（5 分鐘）與能量恢復時間（每 10 秒 1 點）；已依 `game.cgi`、`basic.cgi`、`town_lib.pl` 核對初始配點、初始金錢、職業經驗、精通與薪資公式。

**保留差異：** 原版角色狀態包含飽足、疾病及體格評價，會影響工作經驗。由於這些系統尚未移植，Web 版目前固定使用原版「普通」狀態的經驗基礎值，再加入原版 1 至 5 點隨機值。

**學校與健身房說明：** 原始 `manual.html` 確認學校每天一堂課，資料表定義了學習費用、能力增加與頭腦能量消耗；健身房資料定義了費用、能力增加、身體能量消耗及「間」欄位。由於此 fork 缺少完整學校／健身房操作流程，Web 版將「間」暫視為分鐘，並以**完成的健身課程**決定下次可訓練的時間，無法透過更換課程繞過。原始效果欄中的「美」及其他特殊影響尚未實作，不會被當成已忠實移植的規則。

一天的判定預設使用 `Asia/Taipei` 時區，可在啟動前設定 `GAME_TIMEZONE` 為有效的 IANA 時區，例如 `Asia/Tokyo`。單機與多人伺服器各自控制日期，不採信瀏覽器自行回傳的時間。角色的原始註冊性別只有男／女，Web 版另提供「未指定」作為擴充。原版銀行利息和會計明細尚未啟用。初次登入已建立的舊版 Web 測試角色會自動增加資料欄位，但**不會重置其原有能力值、金錢、身高或職業**。

**資料備份：** 更新前請備份 `web/data/`；資料表會自動添加職業經驗、精通、體重與訓練時間欄位，遷移沒有反向自動還原。

## 城鎮地圖與原版資料匯入

原始地圖不是圖片檔，而是 `log_dir/townlog0.cgi` 至 `townlog3.cgi` 中的一行 `<>` 分隔資料。每座城鎮使用 **12×16 格**，原始布局的 A1 位於第 22 欄（從 0 起算），L16 位於第 224 欄；其他城鎮名稱、人口、經濟與預留欄位不會在匯出時任意刪除。

**目前這份 fork 的四個 townlog 檔案全部為零位元組，沒有原始建築配置。** Web 版會正確顯示「尚未配置的空白街區」，不會擅自產生冒充原版的地圖。單機玩家可在網頁上開啟街區編輯模式，選用從原始 `unit.pl` 對應的設施與圖示；未識別的原始符號、居民建築會保留代碼並以待辨識狀態顯示。尚未匯入房屋詳細紀錄時，不會假造屋主或內部裝潢。

若有其他伺服器保存的原始 townlog 檔案，可在 `web/` 資料夾中匯入（指令需在同一資料庫使用者權限下執行）：

```sh
node scripts/town-map.mjs --town 0 --mode solo --import ../log_dir/townlog0.cgi
node scripts/town-map.mjs --town 0 --mode multi --import ../log_dir/townlog0.cgi
```

如果城鎮已配置，工具會拒絕覆蓋。確認備份後，才可明確加入 `--replace`。輸出為可由原版讀取的 UTF-8 分隔資料：

```sh
node scripts/town-map.mjs --town 0 --mode solo --export ./town0-export.cgi
```

多人模式的地圖由伺服器共用，**不允許普通玩家透過 Web API 修改**。目前多人模式需透過伺服器端 CLI 匯入地圖；多人管理員編輯介面、住宅買賣與設施互動尚未完成。單機模式預設僅監聽本機回環位址，不應改成對外公開的未驗證編輯介面。

在匯入或編輯前請先備份 `web/data/`。此功能會新增 `town_maps` 資料表，不影響已建立的角色、工作或訓練資料。
