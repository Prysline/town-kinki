donut.cgi／town_ini.cgi
原版牌桌與 Web 單機適配

五種點數 1～5 等機率抽一張，選比前一張「高」或「低」。猜對獲得牌桌累積張數 × 10,000 元；猜錯扣除同額並重置桌面為這次抽到的一張牌。抽到同點數時，原版設定為獲勝且金額 × 2。原版遊戲紀錄是一張跨玩家共用牌桌，原始空檔首次抽牌時前卡未設定、數值比較按 0 計算，桌上預設一張「1」；因此第一局猜高必勝、猜低必敗，這不是 Web 另外設計的機率。遊戲原始設定為10分鐘間隔，還有依未確認的連抽旗標控制相鄰玩家回合；Web 單機允許本人在滿10分鐘後接續玩，並以帳號隔離本人歷史、保留共用牌桌。必須在有「ゲーセン」的城鎮且有足額現金。所有抽牌及獎懲由伺服器處理並防重送。

三種原版抽牌規則及 Web 單機適配

三種遊戲各有自己一張跨玩家共用牌桌，從原版空白紀錄初始化為一張「1」牌。第一種「不同點數×1萬元」抽1～5點，與前一張不同時獲得累積張數×10,000元，相同時扣同額並重置牌桌；原版沒有啟用卡牌10分鐘限制，但禁止同一玩家連續抽牌，Web 單機改採原版5秒全域行動限制後可再抽。第二種「不同點數×2萬元」同樣抽1～5點，收益與損失均為累積張數×20,000元，原版每人10分鐘間隔。第三種「相同點數×10萬元」抽1～3點，相同時獲得累積張數×100,000元並重置牌桌；不同則固定扣除100,000元、牌串再增加一張，原版每人10分鐘間隔。原始空桌的前一張：第一、二種未設定，Perl數值比較0，因此首次抽牌必為「不同」；第三種明訂首次比較點數1。Web 版讓單機玩家達到限制時間後接續牌桌、必須有足額現金，使用伺服器抽牌、SQLite原子結算與防重送；本人紀錄最多顯示20局。多帳號共用三張不同的桌面，但交易紀錄仍分開。原版連抽旗標未確認為啟用狀態，不宣稱兩者完全等價。
