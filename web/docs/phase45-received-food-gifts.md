# 第 45 階段：原版受贈食品／速食可真正使用（2026-11-21）

## 原版直接證據

- `gifutoya.cgi::gifutoya_do` 約第 195～231 行：把本人 `食料品` 轉為 `ギフト` 前，若效果欄沒有 `食料品`，便在尾端增加 `,食料品`；`ファーストフード` 增加 `,ファ`；然後移除 `ギフト` 和 `無,` 等文字。例：`無` 食品成為 `食料品`；`縮み,1` 食品成為 `縮み,1,食料品`。
- `command.pl::gift_souhu_syori` 約第 2942～2990 行：寄件人扣耐久後，收件人得到 `ギフト商品`，效果中的 `ギフト` 字樣清除，保留食品標記；重算購入日期、單價 0 元及寄件附註。
- `basic.cgi::item` 約第 2118～2140 行：讀取已收禮品時，若效果欄含 `食料品` 或 `ファ`，原版將 `ギフト商品` 的類別改回 `食料品`／`ファーストフード`。原版 `item_do` 約第 2410～2450 行把這兩種類別當成食物，套用共同 `$syokuzi_kankaku` 60 分鐘冷卻，並記錄 `$last_syokuzi`。
- `dat_dir/syouhin.cgi`：`食料品／牛丼弁当`（`無`、720 kcal）、`食料品／チヂミ`（`縮み,1`、300 kcal）、`ファーストフード／特級幻バーガー`（`無`、800 kcal）可驗證三種食品禮品案例；`ちゃんこ／どすこいスーパープレゼント` 的 `ウエイトアップ,1,ギフト` 不代表食物。

## 本次修正

- `web/src/legacy-item-use.mjs::parseArchivedItem`：僅當持有物分類為原版「已收禮品」`ギフト商品` 且特殊欄位是 `食料品`、`ファ`，或有效 `效果,數值,食料品/ファ` 格式，才按原版辨認為食品／速食。獨立 `食料品`／`ファ` 是轉禮時 `無,` 被移除的合法結果，實際使用等同無額外特殊效果；有效三段格式仍按第一、二段執行能力、體重、疾病或身高效果。
- 此變更讓收禮者的 `listLegacyItemActions` 真正顯示可用，`useLegacyItem` 透過既有安全交易寫入角色效果、耐久及使用紀錄，並共用 60 分鐘最後用餐冷卻；剩餘不足、請求防重及個別道具間隔照舊。
- Web **不改寫**原版 33 欄及收禮來源欄位，而是在使用時推導「這項已收禮品應按食品結算」；因此資料庫與原始紀錄仍保留 `ギフト商品`，這與 CGI 在開啟物品清單時直接改寫分類有可追蹤差異。
- 普通未寄出的 `ギフト` 仍不可直接使用；`ギフト` 字尾的非食品特殊商品仍可在收件後使用，但不觸發餐點冷卻。畸形、負特殊幅度或未知三段尾碼不可直接使用。
