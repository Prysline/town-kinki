# 第 50 階段：單機首次遊玩流程稽核與空白街區試玩配置

日期：2026-11-21。**本階段開始依使用者新的優先順序，先讓單機角色能持續遊玩**；多人原有功能保留但不搶占近期開發優先度。目標整合分支 `feature/web-dual-mode-phase1`，原版 `master` 保持不動。

## 一、這一輪已確認的實際阻塞

原版儲存庫 `log_dir/townlog0.cgi`、`townlog1.cgi`、`townlog2.cgi`、`townlog3.cgi` **四份檔案大小都是 0**。Web 啟動時 `src/town-storage.mjs::bootstrapLegacyTownMaps` 只在原始檔不為空時匯入；沒有任何原始街區可匯入，因此初次單機角色進入 `/api/state` 時，`map.configured=false`，顯示 12×16 空白地圖。

這不是「原版街區長這樣」的證據，也不是應當隨機編造四座歷史城市的理由。已有地圖編輯器可逐格新增建築，但單機玩家若不知道必須自行編圖，直接點選地圖會沒有百貨店、裝備屋、販賣機、住宅空地等實際玩法入口；伺服器的 `retail/buy` 等會因所在城鎮不存在對應建築而拒絕。工作、銀行、學校等已有部分城鎮快捷入口，沒有全部阻塞。

## 二、本階段修復（不冒稱是原版原始地圖）

在 `src/solo-starter-town.mjs`、`src/server.mjs`、`public/index.html`、`public/app.js` 增加**明確自行選擇、不可覆寫**的單機試玩街區：

- 只有單機模式、已建立角色、該角色**目前所在地**尚無任何 `town_maps` 配置且該城沒有任何住宅時，才能呼叫 `POST /api/solo/map/starter`。不信任客戶端傳入的 `townId`；從存檔角色決定所在地。
- 玩家從空白地圖旁邊按「建立這座城鎮的單機試玩街區」，必須先確認。**不自動修改**真正遊玩既有地圖、不擅自安排原版歷史街區、不補貼資金或能力；同一座城鎮重複使用會拒絕。
- 原第50階段使用 `MAP_SYMBOLS` 的 16 個原版建築代碼：A1～A4 `駅／職安／銀行／病院`；B1～B4 `食堂／食堂２／デパ／デパ2`；C1～C4 `自販機／装備屋／教室／建築`；D1～D4 `空地／空地2／リサイ／空地3`。**第51階段**依原版 `unit.pl` 追加 D5 `クーポン` 兌換所，第53階段再加入 D6「販売1」餌料店、D7「釣り」釣場；第54階段加入 D8「合成」合成屋；第55階段再增設 D9「ゲーセン」遊樂中心，因此**目前新建立的試玩街區為21格、其餘171格空白**；既有16／17格或玩家已配置街區全部不會覆寫，使用者可自行用地圖編輯器補建。所有設施仍用正式交易 API。
- SQLite `BEGIN IMMEDIATE` 內檢查現有地圖和住宅，使用原本 `storeTownMap` 入庫，失敗整筆回滾，標示資料來源 `web-solo-starter`；後續地圖編輯、住宅建造仍經現行交易與權限。**已有任何地圖紀錄（包括曾自行編輯或手動載入原始世界資料的地圖）、即使配置內容為全空地圖，以及已有住宅的城鎮，都不覆蓋**。
- 前端標示「這不是原版歷史地圖」。使用者不點按初始化時，仍保持原本空白街區及逐格編輯模式。單機玩到其他仍空白的城鎮，可在該城自行獨立選擇是否建立即可遊玩的試玩地圖。

## 三、以單機玩家可能接觸的系統重新分級

以下為**從目前實作與原版 CGI／資料來源可確認的程式狀態**，不是實際 Chrome／手機視覺驗收：

| 單機操作 | 現況 | 優先後續實際驗收 |
|---|---|---|
| 建立角色、登入／繼續、單機時間 | 核心已實作，建立時按原版分組配點；可返回首頁、保留同一個角色及快轉 | 新版 Web 角色備份還原、不同設備、遊戲日跨日邊界 |
| 工作、發薪、轉職、銀行 | 核心已實作，薪資現金／銀行與工作冷卻已由第48階段回歸 | 長週期出勤、實際 UI、原版工作條件餘下差異 |
| 城鎮地圖與首次探索 | 原版四份真實地圖檔是空檔；**第50階段新增可自願建立的 Web 單機試玩街區**，已有圖不改 | 取得真實原版街區檔後做唯讀匯入、不同城鎮導覽、視覺與鍵盤操作 |
| 食堂、醫院、學校、健身房與教室 | 已有獨立 API 和現金／冷卻／每日限制測試；學校／健身房原版可執行 CGI 在本 fork 仍無證據 | 原版只有資料表而非完整 CGI 的條件不可宣稱等價；日常循環真正瀏覽器操作 |
| 百貨店、自販機、裝備屋與消耗品 | 實際購買／持有、部分物品可使用；本階段使初始空白地圖可自選配置商店入口 | 商品原版 33 欄效果仍只移植安全子集、交易重送與共同背包限制 |
| 住宅建造、改裝、出售、室內留言 | 核心 API 已存在；試玩街區提供住宅空地可進入；所有原版地價與屋型費仍照原版 | 首都土地極貴：京阪神大街原版地價 **5,000 萬**，不可為新手直接偷改原價；需要實際賺錢進程與遊戲內說明 |
| 每日事件與優惠券 | 第51階段已完成 [Web 事件券的原版30獎品真實兌換](phase51-event-coupon-redemption.md)：扣券／33欄入庫／交易防重，並新增原版兌換所；**原始舊券及部分獎品用途仍未移植** | 優先補可單人實際使用的獎品用途與其原版子 CGI，其他五種原版事件及券來源轉換仍須核對 |
| 釣魚、合成、遊樂中心及部分角色玩法 | **第53階段 [原版釣場、餌料店與魚獲出售已接真人可操作交易](phase53-fishing-economy.md)**；**第54階段 [原版12種合成配方與本人材料扣除已接可操作交易](phase54-crafting-house.md)**；**第55階段 [原版遊樂中心雙骰猜奇偶已能下注與原子結算](phase55-arcade-dice.md)**；**第56階段 [原版High／Low同點雙倍、共用牌桌與10分鐘間隔](phase56-arcade-highlow.md)**；**第57階段 [剩餘3種原版卡牌獨立共用牌桌與實際結算](phase57-arcade-donut-trio.md)**；**第58階段 [原版loto.cgi六位數即時樂透下注與7倍率結算](phase58-instant-loto.md)**；**第59階段 [原版loto6.cgi定時／200注開獎與普通銀行原子匯款](phase59-loto6-draw.md)**，福引及寶箱等仍待核對 | 持續驗釣魚新Web存檔與手機瀏覽器，後續遊樂中心與其餘物品用途需逐項核對來源、入庫、扣款與冷卻，不做假入口 |

## 四、測試／驗收邊界

- `web/tests/solo-starter-town.test.mjs`：原版建築代碼白名單、192 格中新建街區目前 21 格配置（第51階段增設兌換所、第53階段增設餌料店及釣場、第54階段增設合成屋、第55階段增設遊樂中心）、來源標記、僅所在地、拒絕覆蓋已有地圖（包括空白但已配置）、有住宅的城鎮拒絕、SQLite 寫入故障完整回滾。
- `web/tests/server.test.mjs`：單機角色不能在建角前初始化、可選擇一次配置、客戶端冒填別的城鎮無效、實際工作與銀行存款、實際百貨商品購物與入庫；以**測試資料庫注入足額現金**驗證原版高額住宅費仍按原價扣除，已建屋格不可覆蓋；關閉 Node 並保留 SQLite，在全新程序重啟後角色、銀行、工作、百貨紀錄、地圖和房屋仍在。多人模式拒絕初始化，已有地圖不可覆蓋。
- `web/tests/home-ui.test.mjs`：單機空白地圖才顯示入口、確認文字與非原版來源告知、正確發送初始化 API。
- 不等同於已實際使用 Chrome／手機寬度 `375px/768px` 操作或真實玩家舊存檔；本階段只聲稱由 Node HTTP 與 SQLite 自動測試覆蓋到的範圍。
