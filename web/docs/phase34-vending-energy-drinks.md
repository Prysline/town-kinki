# 第 34 階段：原版自販機「効果」牛奶能量恢復（2026-11-20）

## 原始來源證據

- dat_dir/jihanki.cgi 第 1 行「元気ミルク」為「ドリンク／効果」，身體能量消耗 -500、頭腦 0；原版自販機讀取檔案首行為控制資料而不選此行，但原始道具欄位仍可匯入／檢驗。
- 第 2 行「爽快ミルク」為「ドリンク／効果」，身體能量消耗 0、頭腦 -500，確實位於原版自販機抽選池。
- basic.cgi::item_do 在第 28／29 欄扣除能量，原始負消耗代表恢復；「効果」沒有另外的特殊分支，亦不代表無限恢復。原版有單品使用間隔與可選的全局飲料冷卻；Web 本次只宣稱單品間隔等有明確資料的部分。
- Web 的 recoverEnergy／maxBodyEnergy／maxBrainEnergy 為原有角色能量規則，能量恢復上限仍由人物能力決定，不會無限增加。

## 這次新增

1. web/src/legacy-item-use.mjs 只在本人 33 欄物品為「ドリンク」，商品名稱分別符合真實「元気ミルク」／「爽快ミルク」，且對應能量欄位與原版來源一致時，允許效果字串為「効果」的商品使用。
2. 兩款牛奶的 -500 消耗透過現有能量公式恢復身體／頭腦能量，超出當前上限時截斷；其餘 17 種能力、熱量與體重仍依原版欄位處理，使用一次減一耐久，保留原始 33 欄唯讀紀錄。
3. 同一 requestId 防重送，同品使用冷卻與交易回滾沿用現有機制；任意命名、改成 -501、附加未知效果的假「効果」商品一律拒絕。
4. 原版從自販機實際購入的「爽快ミルク」現可在本人物品面板使用，不需另外宣稱未實作的特殊效果。
