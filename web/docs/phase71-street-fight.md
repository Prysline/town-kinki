# 階段 C：Street Fight（街頭格鬥）移植
基準：9db33c96faace21f4f3ada3fb533a701b44dcc3f。來源：town_maker.cgi:610,786–797；game.cgi:30–400；town_lib.pl:245–275,384–435,477–505,1554–1590；town_ini.cgi:220,531；event.pl:1376 起。未讀取玩家私人存檔。
- 17 項能力沿用 Web STAT_KEYS；16 種攻擊，健康僅參與對手最大身體能量。精神攻擊 1–8、14，其餘身體。傷害為攻方能力減守方能力，非正數無傷害；速度較高的本人先攻，平速對手先攻，交替最多 50 次。每擊後依對手身體、對手頭腦、本人身體、本人頭腦判斷。本人使用現有能量、對手以原版獨立公式計算滿能量。
- 勝利每次攻擊 1500 元，敗北每次 300 元，平手不改現金。勝利 1/10 機率獲 1–5 張券；所有已交戰結果獨立 1/10 機率 K 點 -3，可為負值。本人能量低於零才歸零；對手只用戰鬥暫存，原版不寫回對手的現金/能量/能力。不是玩家間轉帳。
- 原版全體 memberlog 抽選 int(rand($#aite_erabi))，最後一列排除且可能抽到本人後無對手。保留此疑似疏漏，Web 以已建立角色的 SQLite ID 作為穩定排序，不限同城；無舊 NPC，不讀取舊名單。僅允許多人同一資料庫實際已建立角色。單機入口顯示無對手，API 拒絕。原版多重註冊旗標/主機限制不匯入；Web 以既有 session、帳號隔離、POST、同源檢查及獨立資料庫約束，不能指定對手或戰鬥參數。
- 原版預設行動間隔 5 秒，從 town_maker 頁面 access_byou 檢查，battle 不更新 access_byou。Web 直接 POST 必須有 5 秒持久化冷卻（包括抽到本人），不移植私人帳號特別間隔，亦非全系統共享冷卻。請求碼本人唯一、重送返回既有結果；SQLite BEGIN IMMEDIATE 保護本人能量、現金、券、K 點、稅基及歷史。
- **待使用者核可的相容性限制**：原版可能輸成負現金；現行 Web 稅務及薪資不接受負現金。正式 API 在抽選前要求最高可能敗北損失 15,000 元現金，不更改核心損失公式，不截斷實際扣款，也不容許先看結果再免費重抽。需另行決策是否支援負現金。K 點維持原版負值；稅務維持原版 <25 無折扣，資料庫遷移保留舊稅務紀錄。
- 尚未完成真人瀏覽器驗收；CI 與 HTTP 驗收結果以實際 run 為準。此 PR 保持 Draft，不合併。

負 K 點亦可繼續領取原版蟑螂挑戰 +3；修正 Web 既有非負驗證，並新增稅務舊表遷移與獎勵回歸測試。優惠券為現行獨立整數餘額，非背包裝備欄，安全整數溢位整筆回滾。
