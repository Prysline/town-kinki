> 查核日期：2026-11-20。比較來源：此 fork 原版 Perl／CGI 與 `feature/web-dual-mode-phase1`（至少包含 PR #22～#29）；來源詳見 [差異矩陣](migration-audit.md)、[43 個地圖入口](phase30-entrypoint-coverage.md)、[職業／教室來源](phase30-jobs-training-profile-audit.md) 及 [外貌來源](appearance-source-audit.md)。**本文件是待辦與來源追蹤，不代表已完成程式移植或實機驗收。**
>
> 狀態定義：**A 尚未深入盤點**＝只找到入口／分流／資料，未完整查證執行規則；**B 已盤點未完成**＝已找到原版實際執行依據，但 Web 缺乏整體或部分功能；**C 核心已修待驗收**＝已完成相應程式和測試但未完成原版真實檔／實際瀏覽器／全流程等價驗收；**D 不可當作已確認功能**＝無法確認可達、缺檔或只見字串。
>
> **避免誤判**：檔案存在、圖片或按鈕存在，均不證明功能可在這份 fork 正常進入。沒有可定位來源的視覺連動、裝飾功能、效果或商品，不建立「待移植」任務。不同的 `looks`、BMI、本人 `kounyuu`、C 聯賽 `ch_gazou` 和自填真實個人檔案不可合併為虛構外觀系統。原版高風險行為（負存款、刪玩家、公開個資）不可直接複製。

## 1. 範圍與目前覆蓋

- 目前倉庫根目錄約 **67 支 `.cgi`／`.pl` 程式檔**（包括可能空白或僅有資料的檔案），**不等於 67 個互相獨立且可用的功能**。有一些功能在 `command.pl`、`basic.cgi`、`town_maker.cgi` 或其他子函式，不能只看檔案數。
- [`unit.pl`](../../unit.pl) 定義 **73 個地圖代碼、43 個互動表單入口、30 個非表單地景／裝飾**。對比現有 [`town-map.mjs`](../src/town-map.mjs) 與 [`town-home.js`](../public/town-home.js)：**28／43** 有 Web 地圖代碼，其中 **8 個**有對應可操作入口（7 個 `FACILITY_PANELS` + 車站 `駅`），**20 個**有圖示但點擊為 `unavailable`，另外 **15 個**尚無地圖代碼；這是**路由數量，不是功能完成比例**。
- 原版 `log_dir/townlog0.cgi`～`townlog3.cgi` 在 fork 為空，不能推定 43 入口都曾經出現在真實可抵達的城鎮地圖。
- 此次再次從 [`gamerand.cgi`](../../gamerand.cgi) 發現**一個地圖入口可再連多個 CGI 遊戲**；43 入口只是第一層，不能視為完整的功能總數。首頁 [`town_maker.cgi`](../../town_maker.cgi) 亦另有快捷、角色設定和社交入口。

## 6. 後續實作次序與安全門檻

1. **原版持有物、購物／交付／庫存的交易基礎**：逐 CGI 核對可執行來源，先解決原子扣款、物品所有權、有效期、背包容量及重送；不要先製造虛構通用商城。
2. **每日食堂、原版優惠券兌換、缺少的五個事件**：沿用經查實的商品與交易／庫存模型，先確認日菜單抽選與獎勵來源。
3. **逐一獨立設施**：釣魚、股票、拍賣、遊樂中心、住宅商業等依可執行分支建立各自驗收，不能由 `unit.pl` 名稱推導完整機率／結算。
4. **安全與真實驗收並行**：帳號權限／登入防濫用、備份／回滾、375／768px／桌面實機，及取得使用者授權的真實舊存檔後再標註移植相容。

**記錄工作不等於功能修正**。原版 `master` 不更動；在完整來源、欄位、條件及測試可查證以前，不自行建立不存在的功能。
