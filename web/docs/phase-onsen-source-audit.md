## 已知來源差異，不擅自修正

1. 原版入浴／選單上限公式加 1，出浴不加 1；兩者也不同於現有 engine.mjs 的 Web 一般上限。初始每項 20 時，原版入浴 22/24、出浴 21/23、Web 25/35。先將來源模型與 Web 共用恢復隔離，不能隱性全站變更。
2. 原版選單以松浴倍率及 +1 暫算（不寫入）；銀浴列顯示金浴時間變數。來源模型輸出銀浴公式，尚未決定正式 UI 如何標示此顯示錯誤。
3. 入浴實際將上次能量時間至現在的整段以所選倍率計算，再 +1；出浴以原版另一上限及倍率計算，不額外 +1。原版重送入浴表單會再扣款，Web 必須遵守既有交易防重、伺服器時鐘與現金安全政策。
4. 銅浴抽兩次 rand(10)+1，結果 <=3 才提升體力／健康；銀浴抽七次 rand(20)+1，金浴抽十七次 rand(20)+1。銀／金存在 tairyoku_up 與 tairyku_up、speed_up 與 spped_up、$$kyakuryoku 等拼寫及符號引用異常。不得直接按表面意圖改成均等 50% 增益，需以完整原版隔離執行差分確認能力與 RNG 消耗。來源另抽背景圖片；此 PR 不執行 RNG 或能力加成。
5. 原版普通/高級浴池直接扣現金，未在本段發現城市貢獻寫入；AP-06 城市貢獻另有來源，不預設兩者連動。
6. 入浴期間其他操作、切換浴池、原版全域行動間隔及 Web 重新整理／重啟／快轉的契約尚待核定。不能把純來源投影直接當正式交易。
