# 第 42 階段：原版百貨特殊道具實際生效／日制一般商品使用（2026-11-21）

## 原版來源

- `basic.cgi::item_do`（第 2395～2583 行）從 33 欄原版持有物資料讀取能力增減、特殊代碼、能量消耗、熱量及使用間隔，使用時更新真實角色狀態。
- `basic.cgi` 先將 `syo_kouka` 依逗號切出前兩個參數；多段字串中的第三段 `食料品` 或 `ファ` 是商品販售後的分類提示，**不是額外特殊數值**。基本能力與熱量仍按原始 33 欄生效。
- `basic.cgi::item_do` 只在耐久單位是 `回` 時扣一次耐久，`日` 的商品由原始購入日期及 `int((現在時間-購入時間)/86400)` 計算剩餘有效天數，同一天可按使用間隔再次使用。有效天數過期就不讓 Web 再用；原始 Perl 有部分繞過 UI 可濫用過期道具的路徑，Web 不移植該缺口。
- `ステータス` 與 `効果` 在 `basic.cgi::item_do` **沒有獨立效果分支**，不應憑空補另一個增益；只有原版商品本身已有可核實的 17 項能力與負能量消耗才可認列。

## 新增可實際使用的商品

1. 原版商品表四款明確的 `効果` 恢復商品：`元気ミルク`、`爽快ミルク`、`元気パフェ`、`爽快パフェ`。其中牛奶已由前期完成，本期新增兩款甜點；必須逐一匹配原始類別、品名、`効果` 及身體／頭腦能量欄位的精確 `-500` 組合，無依據的同名偽造效果仍拒絕。
2. 三款原版 `ステータス`：`バイオハザード（wiiバージョン`、`キングダムハーツ2ファイナルミックス＋`、`阪神タイガースの公式チケット`。僅將原版已有的能力及能量消耗套用，沒有捏造額外加成。
3. 原版三段效果：`どすこいスーパーちゃんこ`（`ウエイトアップ,1,食料品`）、`どすこいスーパーつまみ食い`（`ウエイトアップ,1,ファ`）和 `断食セット`（`ダイエット,30,食料品`）。實際增加／減少體重，並按照買入後的食品／速食類別共用用餐冷卻；不額外套用第三個參數。注意原版 `断食セット` 基本價格是 **0**，依目前百貨正價商品驗證不能從百貨直接購入；本次只測試既有合格原版持有物的使用效果，不宣稱它有上架。
4. 原版 `日` 耐久的普通用途書籍、遊戲與成人用品類別：要求本人真實購入日期與 33 欄完全相符，使用間隔已過、目前仍在有效天數內才可操作；操作時保留原始物品有效期，**不會每用一次扣掉一天**。每日剩餘天數動態依遊戲時鐘計算。其他具有獨立用途的 `健康保険`、信用卡、禮品、寵物及防犯攝影機仍不允許走一般使用 API。

## 實際工程界線

- 仍由 `web/src/legacy-item-use.mjs` 的安全白名單管控，不改原版 `member/<ID>/mono.cgi`；`legacy_item_usage` 單獨記錄使用日期與歷史，原始物品 33 欄保持唯讀。購物、庫存、銀行付款沒有改動。
- `supportsLegacyItemUse` 供商店在購入前查看「買入後是否支援使用」；原始商品表尚未填寫購入時間（可能放的是 `きょろちゃ`、`ソラ` 等製作者文字）的 `日` 商品使用安全預覽日期，**不**代表可以繞過正式購買時間與到期判斷。
- `web/public/app.js` 現在解釋 `ステータス`、`効果` 與第三段分類標記的確切意義；未核實的 `万能,` 空數值等效果仍保留「尚未支援」，不擅自補成 0 或假設治療效果。
- `web/tests/legacy-item-use.test.mjs` 加入真實商品表逐筆驗證、合法與仿冒恢復、食品與間隔、日制到期／重用／原始日期核對、特殊權益分流與重送防重。另增 `web/tests/retail.test.mjs` 的商店預覽用途回歸，`web/tests/server.test.mjs` 真實百貨購買→使用的 API 整合情境，`web/tests/home-ui.test.mjs` 商品用途說明測試。

## 尚未全等

- 未補原版 `ランダム品` 的亂數能力、`万能,` 等缺漏／錯字商品、寵物、裝備、信用卡附加優惠與安全設備的獨立效果；它們需要先確認所屬設施及實際觸發點。
- 原版存在 `oyatu_kisei` 飲料／甜點／酒類跨物品全域冷卻旗標，Web 仍以每件物品與食物共用冷卻控制，尚未宣稱完全等價。
- 原版歷史玩家實測與真正瀏覽器互動測試不在本次 CI 內。
