## Web 差異與限制
- B 聯賽專用五秒冷卻、帳號隔離、請求 ID、同一 SQLite 交易保存角色能量／現金／K 點、裝備、獎品及收據；歷史只查本人。普通敗北金錢最低零，不產生負資產。損壞裝備須鍛造修復次數才可再次裝備。
- 原版 mono.cgi 的容量判定先於同名堆疊；Web 以目前可見的持有物及未穿戴裝備格計算，不覆寫原版封存或把舊匯入物合併。
- 原版 MB 四藥草耐久單位為空，33 欄保留原始值（購入日更新）。只對來源為 __web_b_league__ 且固定欄位與四種原版藥草完全相符的物品開放使用。原版 basic.cgi::item_do 僅在耐久單位為「回」時扣次數，故保留空白單位及數量；5/10/15/20 分鐘冷卻、體力及健康各 +3/+5/+10/+50、疾病指數 +5/+10/+15/+20（沿用現有 Web 對原版万能判斷引號拼寫錯誤的相容修正）。不接受歷史匯入或未知空白單位物品。
- 單機玩家可在城鎮編輯放置「Ｂリーグ」；不改既有初始地圖或使用者地圖。多人需城鎮已配置建築。
- 不移植其他 CGI 戰鬥、原版私人存檔或全域行動冷卻；未經瀏覽器實測及 CI 不宣稱驗收完成。
