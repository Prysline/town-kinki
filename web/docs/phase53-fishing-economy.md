# 第53階段：單機優先——原版釣魚、魚餌商店與漁獲競價

> 2026-11-21；依 [現行專案範圍](project-scope-no-legacy-player-import.md)，本階段**完全不做原版舊玩家存檔匯入、轉換或相容驗收**。原版 CGI／商品資料只用來還原新玩家的玩法，新增內容寫進新版 Web SQLite；原版 `master` 保留不動。

## 一、原始碼依據與真正可玩支線

- `unit.pl::%unit`：原版 `釣り` 導向 `sea.cgi`，`販売1` 導向 `hanbai1.cgi`；地圖格和建築都要真正存在才可操作。新建 Web 單機試玩街區由原來 D1～D5 延伸至 **D6 餌料商店／D7 釣魚場**，共19格；已配置的既有玩家地圖絕不自動覆蓋，可手動放置。
- `hanbai1.cgi` 明定 `$hanbai_hinmoku='餌'`，從 `dat_dir/syouhin.cgi` 提供四種原始餌料，依**原價**銷售（不是百貨原價×3）：`小エビ` 100 日圓／1 回，`魚ルアー（小）` 500／5 回，`魚ルアー（中）` 1000／5 回，`魚ルアー（大）` 5000／5 回；原版來源庫存分別是 50／25／25／25 件。Web 目前依遊戲本地日界重設這四款原始庫存。**原 `hanbai1.cgi` 以當日 01 時的旗標刷新；這是已記錄的 Web 時點差異**，不聲稱毫秒級等價。
- `sea.cgi::turu` 每次實際消耗一件本人持有的 `餌` 或普通 `魚` 一回；此消耗來自 `event.pl::motimono_kensa_ev2`。原版 `$turi_kankaku=100` 秒，即使沒有釣獲也消耗餌料並設置冷卻。原版 `$my_rand=int(rand(3))` 意味每組**只有前三種獎品能抽到**，雖然程式排列四種； Web 不製造第四件「甜甜圈、章魚燒、載具、軍艦」作獎勵。
- `sea.cgi` 依所用餌料決定四個級別，機率分母為 2、3、5、7 之一：各級別真實可抽取的魚分別 `小魚／ミニたこ／ホタルイカ`、`中くらいの魚／クラゲ／スルメイカ`、`でかい魚／ウツボ／ミズダコ`、`サメ／海がめ／マグロ`。釣魚隨機與亂數範圍有單元測試核對；前端不得自報「釣到哪一種」。
- `sea.cgi::seri` 與 `event.pl::motimono_kensa_ev2` 確認本人持有真魚、扣一回後按原版 `int(rand(max))+1+base` 計算售價。不同魚種依來源使用 `(max,base)`：小魚類 (100,50)、中魚類 (500,200)、大魚 (1000,2500)、ウツボ (5000,2500)、ミズダコ (3000,2500)、サメ (50000,50000)、海がめ (100000,50000)、マグロ (200000,50000)。只在釣場允許販售。
- `town_ini.cgi`：原版一般物品最多25格、同款最多5份；釣到的魚在 Web 以原始33欄商品保存，實際剩餘數量存在 Web 物品使用帳本，而不是僅加一個虛假的捕魚數字。部分先前來源的道具可以有不同專用行為；餌料／魚獲不走通用藥品「使用」按鈕。

## 二、Web 操作及 SQLite 資產安全

- 新增 `web/src/fishing.mjs`、`GET /api/state` 的 `fishing` 區塊、`POST /api/fishing/bait/buy`、`/api/fishing/cast`、`/api/fishing/sell`。伺服器從已解析的原始 Perl 與商品目錄核對物品、價格、機率、真實地圖；使用者只可指定**本人真實持有物行號**或伺服器核准餌料 SKU，不能回傳任意魚或自己填價格。
- `BEGIN IMMEDIATE` 鎖定扣現金／庫存、扣餌與隨機魚獲、扣魚與賣魚收入，連同 `fishing_transactions` 請求防重紀錄一起提交。失敗回滾全部操作；重送相同 ID 不重複扣款、扣餌或產生魚獲，換品或換動作拒絕。
- 餌料與漁獲寫入本人 `legacy_inventory_items` 的 `__web_fishing__` 來源與完整原始33欄；使用本人的 `legacy_item_usage.remaining` 當作實際剩餘回數；在背包中顯示真正的剩餘回數與「至釣場操作」的正確用途。魚類同款達5份、一般背包達25格則拒絕超量獲得，防止重複交易與物品溢位。
- `fishing_cooldown` 使用遊戲時間 `gameNow()`，單機時間快轉可跳過100秒，不以真實牆上時鐘繞過限制。多人模式保留真實伺服器時鐘及每人獨立的物品／現金；單機優先但不破壞多人權限。
- `public/index.html`、`public/app.js` 增加原版販售店、釣魚與競價市場的實際操作面板、可用項目、原價及庫存、確認操作、釣魚倒數、交易紀錄；來源文字以 `textContent` 處理，避免以玩家提交的物品名注入 HTML。
