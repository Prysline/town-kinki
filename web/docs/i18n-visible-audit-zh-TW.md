# 第七階段：Web 玩家可見字串與來源覆蓋率稽核（待書名用語確認）

## 安全邊界

只修正玩家介面顯示及對應測試。保留所有原版 CGI、資料表、交易識別鍵、商品 SKU、日期、耐久、效果、禮品寄送原始資料、玩家自填文字、地圖建築鍵及抽選邏輯。未知名稱或使用者姓名不強制翻譯。

### 本輪實際修復的動態漏譯

- 住宅玩家商店說明原先直接連接 `shop.category`，現只對顯示呼叫 `displayRetailItemCategory(shop.category)`，原始類別仍供進貨、倉庫和販售判定。
- 三處付款卡片選單使用原始 `card.name`：住宅玩家商店、百貨商品表、教室學費信用卡。現在顯示為 `displayRetailItemName(card.name)`，仍用原始 `sourceLine` 決定付款卡片。
- 已存在信用卡譯名直接沿用：`クレジットカード`「信用卡」、`ゴールドクレジットカード`「黃金信用卡」等，並未為本輪創造重複名稱。
- `web/tests/i18n-visible-audit.test.mjs` 加入來源核對、413/417 來源差別、69 筆餐點、150 個職業、HTML 假名掃描、動態入口與原始鍵回歸。

### 不應視為漏譯的內容

- `web/src/town-map.mjs` 及 `web/public/town-home.js` 的 `ゲーセン`、`ギフト屋`、`リサイ` 等是地圖來源代碼；玩家顯示使用「遊樂中心」「禮品店」「回收商店」。
- `app.js` 中 `スーパー`、`ギフト`、`ローラースルーゴーゴー` 等只用於條件及原始效果解析，不能直接改成翻譯鍵。
- 玩家自訂角色名、房屋名稱、商店名稱、公告、站內信及不認得的原版來源名稱不自行改寫。
- 動態後端安全提示已主要使用繁中，但本稽核不宣稱對任意玩家輸入或未來新增的來源名字完成 100% 翻譯。

## 唯一待使用者確認：原版書籍名稱 `成り上がり`

- 原版 `dat_dir/syouhin.cgi` 將其列於「書籍」，隨機事件 `web/src/event-effects.mjs` 也以此 **原始道具鍵**觸發音樂能力加成。現行共用翻譯為「反敗為勝」，前端事件已沿用同一譯名。
- 但日文 `成り上がり／成りあがり` 的核心語意偏向從低位向上爬升、功成名就；「反敗為勝」可能暗示先輸後贏，並不是相同概念。
- 日本角川出版社有 `成りあがり How to be BIG` 的書目：https://www.kadokawa.co.jp/product/200402000410/ ，但來源 `成り上がり` 與該書拼寫不同，不能單靠這個外部對照宣稱官方台灣譯名或確定相同版本。
- 待確認顯示選項：「飛黃騰達」（偏成功出頭）、「白手起家」（偏從零開始）或保留既有「反敗為勝」。在使用者選定前保持原有「反敗為勝」，不擅自更新翻譯字典、事件敘述或原始書名。
