# P1：兩間百貨店實際購物切片（2026-11-20）

## 原版來源
unit.pl L138–140 的 デパ／デパ2 → command.pl::depart_gamen L1404 起產生兩個上架清單，::buy_syouhin L1962 起執行扣款和商品入庫；town_ini.cgi L85–93 為庫存調整與上架數量；商品從 dat_dir/syouhin.cgi 的 33 欄讀取。

## 已經實作
- 從城鎮地圖中確實有配置的 デパ／デパ2 進店，若目前所在地無此建築，API 亦拒絕購買。
- 每間每天各上架至多 110 件原始非「食」商品，原始單價乘 3；全玩家共用各店庫存。日期依 Web 原有 GAME_TIMEZONE 和單機快轉時計算。
- 每次一件、現金付款；由伺服器確認現金、當日貨架、剩餘庫存和 25 格物品容量。前端不能指定售價、庫存或商品 33 欄。
- 同筆 BEGIN IMMEDIATE 交易扣款與庫存、記交易流水號、產生本人實際的 33 欄持有物；原版匯入物品保持原樣，支援已實作的消耗品及符合原始條件的信用卡驗證；未實作效果不虛構。
- 以每位使用者專屬 requestId 防重，錯誤店家、商品、容量、現金不足、庫存不足或後端資料錯誤會回滾。UI 顯示商品、搜尋與前 30 個結果、已購明細。
