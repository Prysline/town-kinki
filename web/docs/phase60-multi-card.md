# 第60階段：原版遊樂中心 Multi Card「多卡」共用倍率

日期：2026-11-22。從 Web 整合分支 \`feature/web-dual-mode-phase1\` 的第59階段合併提交 \`96202858\` 開發。**不修改 \`master\`、原版 Perl/CGI 或原始玩家檔案**。

## 一、原版證據與範圍

\`unit.pl\` 的「ゲーセン」→ \`gamerand.cgi\` 的 \`action="cardw2.cgi"\`／\`<>cardw<>\` → \`cardw2.cgi::cardw\`。此 fork 的 \`log_dir/cardw_log2.cgi\` 為空檔，沒有原版現成倍率、前一位玩家或局數。原始空記錄時 \`if($card_suu eq ""){$card_suu=1;}\`，所以 Web 共用倍率從 **1** 開始，不自行匯入任何假的舊紀錄。

| 課程基本金額 | 原版畫面標示成功率 | 真正成功率（程式實際判定） | 本局現金淨變化 |
|---:|---:|---:|---|
| 10,000 元 | 80% | **79%** | ±（10,000 × 當前倍率） |
| 100,000 元 | 65% | **64%** | ±（100,000 × 當前倍率） |
| 1,000,000 元 | 50% | **49%** | ±（1,000,000 × 當前倍率） |
| 10,000,000 元 | 35% | **34%** | ±（10,000,000 × 當前倍率） |
| 100,000,000 元 | 20% | **19%** | ±（100,000,000 × 當前倍率） |

**為何實際機率比原版標示少1%：** \`$randed = int(rand(100))+1\` 的實際整數是1～100，原版 \`if($cardw_atari[$in{'chk'}] <= $randed)\` 判定**等於門檻就失敗**，因此成功條件是 \`roll < 門檻\`，不是 \`<=\`。此階段以真正的可執行演算法為準，不擅自修成80%、65%、50%、35%、20%。

- 成功時 \`$money += $cardw_r[$in{'chk'}]*$card_suu\`，角色現金**增加賭注全額**，共用倍率加1。
- 失敗時 \`$money -= $cardw_r[$in{'chk'}]*$card_suu\`，角色現金**扣除賭注全額**，共用倍率重設為1。
- \`$cardw_chk=0\`，原版畫面僅在現金足夠時顯示可點的課程。Web 亦在伺服器檢查足額、有效課程與安全整數，避免手工POST造成負現金。
- \`@cardw_k_time=("0","0","0","0","0")\` 是**實際啟用**的五個課程冷卻，原碼之前有被註解的 \`# @cardw_k_time=("15","20","25","30","35")\`，不能拿來當現行限制。
- **原版禁止同一位玩家緊接在上一位玩家之後再次抽牌**：\`if ($name eq $do_name){&error(...)}\`，不因經過很久就解除；不同玩家可接續倍率。
- 原版全域 \`$koudou_seigen='5'\` 秒限制，各玩家 CGI 行動仍可能受此限制。

## 二、Web 實作與單機差異

- 新 \`web/src/arcade-cardw.mjs\`：啟動核對 \`gamerand.cgi\`、\`cardw2.cgi\`、\`town_ini.cgi\` 來源；剔除註解的舊版15～35分鐘設定；原碼規則改動拒絕靜默啟動。
- \`arcade_cardw_state\`：全服**唯一**共用倍率、最後出牌帳戶與更新時間；\`arcade_cardw_rounds\`：本人請求碼、課程、抽中點數1～100、原版顯示與真正機率、抽前／後倍率、下注額、輸贏與遊戲時刻。個人最近20局由 SQLite 查詢提供，長期帳本不因畫面20筆限制刪除。
- \`POST /api/arcade/cardw/draw\` 僅接受 \`course=0..4\` 和 \`requestId\`；由伺服器 \`crypto.randomInt(100)\` 抽卡（換算原版1～100）。不可由前端指定倍率、勝敗、抽卡結果或獎金。
- 在 \`BEGIN IMMEDIATE\` 交易內驗證本人角色與所在城鎮確有「ゲーセン」、足額現金、全服倍率、上一玩家與冷卻，再同時更新現金、倍率與交易帳本；任一步失敗回滾。相同帳戶同一請求碼回傳原局、不重複結算；跨課程重送被拒絕。
- **多人 Web**：保留原版「同一人不能連續抽牌」。不同玩家可接續同張牌桌；各人只能讀自己的歷史。
- **單機 Web**：原版若硬套「上一位玩家必須不同」，唯一玩家一局後就會永久卡住。因此單機改為同一人每隔 **5秒**（沿用原版全域基本行動限制的量級）即可再玩，不冒充原版專屬卡牌冷卻。這是**刻意且明確**的適配差異。
- 安全差異：超出 JS／SQLite 安全整數賭注或發獎會被拒絕，原版 CGI 部分強制POST、未驗現金等不安全情況不移植。
- 第55～59階段雙骰、四種抽牌、即時六位樂透及定時六號樂透都保留；既有單機試玩城鎮21格，D9「ゲーセン」不變，已自訂地圖不覆寫。
