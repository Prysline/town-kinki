# 第57階段：單機優先——原版遊樂中心剩餘三種抽牌

日期：2026-11-21。新功能分支 \`feature/web-phase57-arcade-donut-trio\` 基於 Web 整合分支 \`feature/web-dual-mode-phase1\` 最新已合併地圖格線修正（PR #75、基線 \`5a4f9c84\`）；原始 Perl/CGI、原版 \`master\` 不修改。

## 一、來源與三種獨立規則

地圖原版「ゲーセン」→ \`gamerand.cgi\` 三種表單入口 → \`donut.cgi::donus\`、\`::donus2\`、\`::donus3\`；與第56階段已完成的 \`::donus4\` High／Low 是**各自獨立**的遊戲。此 fork 對應的 \`log_dir/donutslog.cgi\`、\`donutslog2.cgi\`、\`donutslog3.cgi\` 都是空檔（0 bytes），不能假設匯入任何原版玩家紀錄。

| 模式 | 原始擲牌 | 勝出條件／實際金錢增加 | 輸掉條件／實際現金扣除 | 下一局牌桌 |
|---|---|---|---|---|
| \`donus\` | \`int(rand(5))+1\` → 1～5 點 | **與前卡不同**，累積牌數 × **10,000** 元 | 與前卡相同，扣累積牌數 × **10,000** 元 | 贏：在原本牌串後追加新牌；輸：重設為新牌一張 |
| \`donus2\` | \`int(rand(5))+1\` → 1～5 點 | **與前卡不同**，累積牌數 × **20,000** 元 | 與前卡相同，扣累積牌數 × **20,000** 元 | 贏：追加；輸：重設為新牌一張 |
| \`donus3\` | \`int(rand(3))+1\` → 1～3 點 | **與前卡相同**，累積牌數 × **100,000** 元 | 與前卡不同，**固定扣 100,000** 元（不乘累積張數） | 贏：重設為新牌一張；輸：在原本牌串後追加新牌 |

以上收入／扣款均是角色現金**淨變化**，不是先下注再乘倍率退款，不能把第三種猜錯誤寫成扣牌數×10萬。

### 原版空牌桌與連抽限制

- 三份原始日誌都空白：原版 \`if ($do_narandacard eq ""){$do_narandacard = 1;}\` 讓桌面一開始各有一張「1」牌。此時 \`$do_hiitakard\`（上一位抽到的牌）仍空白。
- \`donus\`、\`donus2\` 首抽把空 \`$do_hiitakard\` 於數字比較當0，任何1～5點都不同，因此**第一局必勝**；是原碼的結果，不是另加保底抽牌。
- \`donus3\` 有不同的執行式 \`if ($do_hiitakard eq ""){$do_hiitakard = 1;}\`，故首次要抽到1才能中獎，機率為1/3；若抽到2或3則固定扣100,000元。
- 原版 \`town_ini.cgi\` 設定 \`$crad_game_time='10'\`（分鐘）、\`$koudou_seigen='5'\`（秒）。**\`donus\` 的10分鐘遊戲時間檢查被註解，並非生效規則**；\`donus2\` 與 \`donus3\` 的10分鐘檢查則仍啟用。
- 原版 \`$renzokuhiki\` 控制同人相鄰出牌：非 \`yes\` 時不准同一人連續出牌；\`yes\` 時同日最多3次連抽。在這份 fork 未見可證明當前旗標為 \`yes\` 的設定，Web 不把它視為啟用。這條多人交替限制若直接套用，純單機環境會因沒有其他人可出牌而永久卡住。
- Web 單機**允許同人**每隔 \`donus\` 5秒、\`donus2\`／\`donus3\` 各10分鐘後續玩；5秒是沿用原版全域基本行動限制，不是宣稱原版第一種有一條生效的專屬5秒卡牌冷卻。多帳號 Web 仍沿用該安全等待時序；沒有硬性套用原版的「上一名玩家不得相同」與同日3次旗標規則，這是明示的 Web 可玩性差異。

## 二、實作範圍與保護

- \`src/arcade-donuts.mjs\` 啟動驗證 \`gamerand.cgi\` 入口、\`donut.cgi\` 三段執行式、\`town_ini.cgi\` 時間設定；原版數值改動時拒絕靜默採用不符的假規則。
- \`arcade_donut_tables\` 建立三個獨立模式的**共用桌面**，各記錄上一張、累積牌串；\`arcade_donut_rounds\` 記錄本人抽牌、基本風險、可能中獎額、實際淨變化、抽前後張數、時間與唯一請求碼。個人最近20局由 SQLite 查詢提供，長期帳本不被畫面20筆限制刪除。
- \`POST /api/arcade/donuts/draw\` 只能帶 \`mode=donus|donus2|donus3\` 和 \`requestId\`；**抽牌由伺服器 \`crypto.randomInt(5|3)\` 決定**，前端不能選牌或修改現金。先驗證所在城鎮真正有「ゲーセン」、本人角色、足額現金與冷卻，再 \`BEGIN IMMEDIATE\` 將本人現金、共用牌串與紀錄寫入同一交易。失敗完整回滾；同一人同一請求碼重播原結果，不能改成其他模式。
- 原版 \`donus\` 不檢查現金；Web 為避免負現金與整數溢出，三種模式一律要求至少持有當局可能虧損的金額，賭注依**伺服器當下桌面**重新核對，不依據畫面舊數字。
- 單機試玩建築 D9「ゲーセン」保持21格，無須再建新格，既有地圖不覆寫；在既有「遊樂」分頁新增三種玩法切換、上張牌、累積牌數、動態收益／風險、冷卻時間、單人紀錄。畫面操作使用 \`textContent\` 安全文字，不以譯名代替原版 \`mode\`。
- 其他第55階段雙骰及第56階段 High／Low 保留，不替換既有資料或遊戲規則。
